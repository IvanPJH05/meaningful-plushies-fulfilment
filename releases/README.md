# MP Packing Station

Download MP-Packing-Station.apk and install on your Android tablet. Version 1.2.0 is the live staff-only packing app with front/rear tablet cameras and USB webcam selection. Demo mode has been removed.

Sign in with an existing fulfilment staff account, wait for CONNECTED, choose a camera, and wait for READY. Scan the individual order barcode, then the matching ID-card barcode. Order scans confirm Packed; completed packing footage attaches to that order.

If replacing an old test build, finish any pending uploads before uninstalling it. This release uses the permanent signing identity; future official releases must retain it.
